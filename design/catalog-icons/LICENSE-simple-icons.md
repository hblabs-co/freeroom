# Brand icons from Simple Icons

The `.svg` files in this folder come from [Simple Icons](https://simpleicons.org),
npm package `simple-icons@16.38.0` (published 2026-11-15). They are unchanged and keep
their original file names (the Simple Icons slug), so `docker.svg` is the `docker` slug.

## Licence

Simple Icons releases its icon files under **CC0 1.0 Universal** (public domain dedication):
https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md

## Trademarks

CC0 covers the copyright in the SVG files only. It does not grant any trademark rights.
Every logo is a trademark of its owner. Freeroom shows a logo only to identify the software
that created a file or folder on the user's disk. This does not mean the owner endorses or
is affiliated with Freeroom. Some owners publish their own brand guidelines (see Simple Icons'
`DISCLAIMER.md`); follow them if a logo is used outside that purpose.

Some brands (for example Microsoft, Adobe, Slack, OpenAI and Parallels) are not in Simple
Icons, often because the owner asked for them to be removed. For those, Freeroom uses the
installed app's own icon (`icon.app`) or an SF Symbol. It does not ship their logos.
