## Install

```sh
brew trust --cask hblabs-co/tap/freeroom   # Homebrew asks you to trust third-party casks once
brew install --cask hblabs-co/tap/freeroom
```

Or download `Freeroom-0.1.1.dmg` below (signed with Developer ID and notarized by Apple).

## Fixes

- **No more freeze while checking the disk.** The animated menu bar icon kept the app's main thread busy for the whole scan, so the window stopped responding (for example after "Skip: rules only"). The animation is now light and only runs while a scan is in progress.
- **First check shows results as they are found** instead of a spinner for a minute. Later checks keep showing the last complete results until the new ones are ready.
- **Uninstall shows its progress:** each step with a checkmark, a "Freeroom was uninstalled" confirmation, any paths that could not be removed, and the app reliably quits afterwards (it used to keep running from the Trash).

## Improvements

- Plugin install instructions now say to choose **"Install for you (user scope)"** in Claude Code, so the plugin works in every folder and Freeroom detects it.
- Settings › About shows the `brew trust` step.

The Claude Code plugin is unchanged (0.1.0).
