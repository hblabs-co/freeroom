## Install

```sh
brew trust --cask hblabs-co/tap/freeroom   # Homebrew asks you to trust third-party casks once
brew install --cask hblabs-co/tap/freeroom
```

Or download `Freeroom-1.0.0.dmg` below. Signed with Developer ID and notarized by Apple.
**Apple silicon and Intel** (universal), macOS 15 or later.

## Freeroom 1.0

The first stable release. Freeroom finds what fills your Mac (Docker and Xcode caches,
`node_modules`, package-manager caches, local AI models, forgotten archives…), explains each item,
classifies it as **Safe**, **Review** or **Keep**, and only deletes what you confirm.

- Menu bar app with Simple and Detailed modes, disk map, grouping by ecosystem.
- Catalog of ~240 known locations with official app icons; accurate measurement (no double counting
  of hard links or APFS volumes).
- Rule engine every 6 hours, no AI involved; at most one notification a day.
- Optional Claude Code plugin (`/freeroom:scan`, `/freeroom:translate`): your own Claude Code
  measures and explains, but only the app deletes, after you confirm.
- History of cleanups and scans, exportable report, 16 languages, text size, light and dark mode,
  complete uninstall.

## What changed since 0.1.1

- **Universal build:** runs natively on Apple silicon and Intel Macs.
- The sidebar keeps its width after the window grows (it could end up squeezed in Detailed mode).
- Releases are now built, signed, notarized and published by GitHub Actions.

The Claude Code plugin is unchanged (0.1.0).
